Middleware : Middleware is a function/code that runs between the incoming Request and the outgoing Response.
           :Middleware is a component that processes an HTTP request before it reaches the endpoint and can also process
            the response before it is returned to the client.
FastAPI request flow:

			Client
			 ↓
		HTTP Request
			 ↓
		Middleware
			 ↓
		Router / Endpoint
             ↓
		Business Logic
			 ↓
		Response
			 ↑
		Middleware
             ↑
	    Client
म्हणजे Middleware ला request endpoint कडे जाण्यापूर्वी आणि response client कडे जाण्यापूर्वी intercept करता येतो.

ASGI = Asynchronous Server Gateway Interface
    :ASGI हा server आणि Python web application यांच्यात communication करण्याचा interface/protocol आहे.
    :Pure ASGI middleware provides lower-level control over the ASGI scope, receive, and send interfaces.
    :BaseHTTPMiddleware easy आहे, पण Pure ASGI मध्ये request आणि response च्या low-level events वर direct control मिळतो.
scope:scope contains metadata about the current connection/request, such as HTTP method, path, headers and request type.
receive:receive is an async callable used to receive ASGI events from the server, such as HTTP request body events.
send:send is an async callable used to send ASGI events to the client, such as response headers and response body.
1. ASGI = Async Server Gateway Interface
2. Pure ASGI Middleware uses:
   scope + receive + send
3. __call__() is the middleware entry point
4. scope = request/connection metadata
5. receive = incoming events
   send    = outgoing events

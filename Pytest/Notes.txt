Fixture Scope म्हणजे काय?
  :A fixture is a reusable piece of test setup/data that pytest provides to your test function.
  :Scope ठरवतं की एखादं fixture किती वेळा तयार (create) होईल आणि किती काळ टिकेल (reuse होईल). 
    डिफॉल्ट स्कोप असतो function — म्हणजे प्रत्येक टेस्टसाठी fixture नव्याने तयार होतं.
@pytest.fixture(scope="function")   # डिफॉल्ट
@pytest.fixture(scope="class")
@pytest.fixture(scope="module")
@pytest.fixture(scope="package")
@pytest.fixture(scope="session")
Scope	         Fixture                                कधी तयार होतं	उदाहरण वापर
function        (डिफॉल्ट)	प्रत्येक टेस्ट फंक्शनसाठी नव्याने	        साधा data, प्रत्येक टेस्टला fresh हवं असेल तर
class	        प्रत्येक टेस्ट क्लाससाठी एकदाच	                क्लासमधल्या सगळ्या टेस्ट्सना same setup लागत असेल
module	        प्रत्येक फाईलसाठी एकदाच	                    त्या फाईलमधल्या सगळ्या टेस्ट्सना same resource लागत असेल
package	        प्रत्येक पॅकेजसाठी (फोल्डर) एकदाच	            कमी वापरलं जातं
session	        संपूर्ण pytest रनमध्ये एकदाच	                Database connection, server सुरू करणे — जड (heavy) गोष्टी

Unit Test vs Integration Test
Unit Test = एक छोटा भाग स्वतंत्रपणे test करणे.  def add(a, b):return a + b
Integration Test = दोन किंवा अधिक parts एकत्र काम करत आहेत का ते test करणे. def test_add():    assert add(2, 3) == 5

Mocking:Testing करताना प्रत्येक वेळेस real payment API call करणे चुकीचे.त्याऐवजी आपण fake object वापरतो.याला:Mocking म्हणतात.
       :Mocking means replacing a real dependency with a fake object during testing.
Mock:from unittest.mock import Mock
MagicMock:from unittest.mock import MagicMock
Q1. What is mocking?
Mocking is the technique of replacing a real dependency with a controlled fake object during testing.
Q2. Why do we mock external APIs?
To make tests fast, deterministic, isolated, and independent of external services.
Q3. What is patch()?
patch() temporarily replaces an object with a mock during a test.
Q4. Difference between Mock and MagicMock?
Mock provides standard mocking functionality, while MagicMock additionally supports Python magic methods.

AAA Pattern
A → Arrange     Test साठी data तयार करणे.      ex:  def test_add():(a = 10b = 20)
A → Act         Function call करणे.           ex:result = add(a, b)
A → Assert      Expected result verify करणे. ex:assert result == 30

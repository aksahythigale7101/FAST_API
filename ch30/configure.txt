-upgrade() applies a migration and moves the database forward.
-downgrade() reverses a migration and moves the database backward.
-autogenerate It compares SQLAlchemy model metadata with the current database schema and generates a migration based on detected differences.
-head means latest migration revision.


-SQLAlchemy → ORM / Database interaction
 Alembic    → Database schema migration


-Difference: create_all() vs Alembic
-Base.metadata.create_all(engine) हे tables create करू शकते.
 पण existing table बदलण्यासाठी ते migration history maintain करत नाही.

Frontend
http://127.0.0.1:5500
     ↓
FastAPI
http://127.0.0.1:8000
Port वेगळा असल्यामुळे browser ला हे different origin वाटते
CORS backend ला सांगतो:"या frontend origin कडून requests allow कर."
Browser security मुळे request block होऊ शकते.यासाठी CORS वापरतो.
----------------------------------------------------------------------------------------------------------------
Web मध्ये "origin" ही संकल्पना तीन गोष्टींच्या combination ने ठरते:
Protocol (http किंवा https)
Host/Domain (उदा. 127.0.0.1 किंवा example.com)
Port (उदा. 5500, 8000)

What is CORS?
  :CORS stands for Cross-Origin Resource Sharing. It is a browser security mechanism that controls whether
    a frontend running on one origin can access resources from another origin.
  :Frontend आणि backend वेगवेगळ्या origin वर असतील तर browser request allow करायची की नाही हे CORS ठरवते.

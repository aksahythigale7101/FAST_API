:AsyncSession-हे database सोबत async पद्धतीने काम करण्यासाठी session आहे.
:async_sessionmaker-याचा उपयोग नवीन AsyncSession तयार करण्यासाठी factory बनवायला होतो.

:async_sessionmaker-"जेव्हा मला database session पाहिजे असेल, तेव्हा या engine वर based AsyncSession तयार कर."
:bind=engine-हा session कोणत्या database engine सोबत काम करणार?
:class_=AsyncSession-तयार होणारा session AsyncSession type चा असावा.
:expire_on_commit=False-expire_on_commit=False → commit नंतर ORM object ची attributes expire होऊ नयेत.
--------------------------------------------------------------------------------------------------------
:async def get_db():-हा FastAPI मध्ये database dependency म्हणून वापरण्यासाठी function आहे.
                  :प्रत्येक request ला database session provide करणे आणि काम झाल्यावर session बंद करणे.
                  :FastAPI endpoint ला session देण्यासाठी.

:async with AsyncSessionLocal() as session:इथे नवीन database session तयार होतो.
           :आणि async with मुळे काम पूर्ण झाल्यावर session properly close होण्यास मदत होते.
:yield session:"FastAPI, हा database session endpoint ला दे."
               :endpoint ला session देतो आणि request lifecycle संपल्यावर cleanup होऊ देतो.

:fLOWCHART = Request -> Depends(get_db) -> get_db() -> AsyncSessionLocal() -> session -> yield session -> endpoint ला db मिळतो
   
:yield का वापरले? return का नाही?
     :return केले तर function session return करेल, पण async with चा lifecycle इथे योग्य dependency pattern प्रमाणे manage होत नाही.
     :yield dependency ला session देतो आणि dependency चा context request lifecycle सोबत ठेवतो.
